Chapter 2 & 3 통합본

📝 데이터 조작과 연결의 마법:
DML, TCL, JOIN

데이터를 단순하게 조회만 하는 것을 넘어, 이제 진짜 데이터베이스에 생명을 불어넣을 차례입니다.

새로운 학생을 등록하고(INSERT), 정보를 고치고(UPDATE), 취소하고(DELETE), 이 모든 변경 사항을 확정(COMMIT) 짓는 과정을 배웁니다. 그리고 관계형 데이터베이스(RDBMS)의 꽃인 테이블 간 연결(JOIN)까지 완벽하게 마스터해 보겠습니다.

✍️ 1. 데이터 넣고 고치고 지우기 (DML)

테이블에 데이터를 조작하는 DML(Data Manipulation Language) 명령어들입니다.

1-1. INSERT (데이터 삽입하기)

새로운 행(Row)을 추가합니다. 모든 칸을 채울 수도 있고, 원하는 칸만 골라서 채울 수도 있습니다.

-- 1) 모든 컬럼에 값을 다 넣을 때는 테이블명 뒤에 컬럼명을 생략할 수 있습니다. (단, 순서 주의!) INSERT INTO STUDENT VALUES('98761234', '홍길동', '컴퓨터정보', 2, 'A', 'M', 170, 60); -- 2) 특정 컬럼에만 값을 넣을 때는 넣고자 하는 컬럼명을 괄호 안에 명시해야 합니다. -- (나머지 명시되지 않은 컬럼은 자동으로 NULL이 들어갑니다.) INSERT INTO STUDENT(STU_NO, STU_NAME, STU_DEPT, STU_GENDER) VALUES('12341099', '홍길동', '전기전자', 'F');

1-2. COMMIT & ROLLBACK (트랜잭션 제어)

-- 방금 넣은(INSERT) 데이터를 하드디스크에 영구적으로 '확정' 짓습니다. -- ❗ 커밋 이후에는 롤백으로 되돌릴 수 없습니다. COMMIT; -- 만약 실수로 데이터를 잘못 넣었다면? 커밋하기 전에 '되돌리기'를 외치세요! ROLLBACK;

1-3. UPDATE (데이터 수정하기)

기존에 있던 데이터를 수정합니다. 한 번에 여러 개의 컬럼 값을 콤마(,)로 이어서 동시에 바꿀 수 있습니다.

-- 홍길동 학생(학번 98761234)이 3학년으로 진급하고 키가 1cm 자랐습니다! UPDATE STUDENT SET STU_GRADE = 3, STU_HEIGHT = STU_HEIGHT + 1 WHERE STU_NO = '98761234'; -- 고유한 학번으로 대상을 지정하는 것이 가장 안전합니다.
⚠️ 매우 중요: UPDATE와 DELETE의 함정
UPDATE나 DELETE 문장을 작성할 때 WHERE 절(조건)을 빼먹으면, 테이블의 '모든 데이터'가 한꺼번에 수정되거나 지워지는 대참사가 일어납니다! 실무에서 가장 많이 하는 끔찍한 실수이니 항상 조건을 확인하세요.

1-4. DELETE (데이터 삭제하기)

-- 조건에 맞는 특정 행을 테이블에서 아예 삭제합니다. (다시 한번 WHERE 절 강조!) DELETE FROM STUDENT WHERE STU_NO = '12341000';

🔗 2. 흩어진 데이터 엮기 (JOIN)

학생 테이블에는 이름만 있고, 수강신청 테이블에는 학번과 과목코드만 있습니다. 이 두 테이블을 합쳐야 비로소 의미 있는 정보(성적표)가 완성됩니다.

2-1. INNER JOIN (두 테이블 연결하기)

두 테이블이 공통으로 가지고 있는 연결고리 컬럼(여기서는 학번 STU_NO)을 찾아 등호(=)로 묶어줍니다.

-- 학생 테이블과 수강 테이블을 '학번' 기준으로 이너 조인(교집합) 합니다. SELECT * FROM STUDENT INNER JOIN ENROL ON STUDENT.STU_NO = ENROL.STU_NO;

2-2. 테이블 별칭(Alias)과 3개 테이블 조인

조인을 하다 보면 테이블 이름이 너무 길어 코드가 지저분해집니다. 이럴 땐 테이블 이름 뒤에 알파벳 별칭(S, E, SUB 등)을 붙여 간결하게 표현합니다.

-- STUDENT는 'S', ENROL은 'E', SUBJECT는 'SUB'라는 별명으로 부르겠습니다. SELECT S.STU_NO, S.STU_NAME, S.STU_DEPT, SUB.SUB_NAME, E.ENR_GRADE FROM STUDENT S INNER JOIN ENROL E ON S.STU_NO = E.STU_NO -- 1단계: 학생과 수강내역 연결 INNER JOIN SUBJECT SUB ON E.SUB_NO = SUB.SUB_NO; -- 2단계: 수강내역과 과목정보 연결
💡 실무 꿀팁
위 코드의 SELECT 부분을 보면 STU_NAME 앞에는 별칭 S.을 안 붙였고, STU_NO 앞에는 붙였죠?
학번(STU_NO)은 학생 테이블과 수강 테이블 양쪽 모두에 존재하는 이름이 똑같은 컬럼이라서 "어느 테이블의 학번을 가져올까?" 명확히(S.STU_NO) 적어줘야 에러가 안 나기 때문입니다!
