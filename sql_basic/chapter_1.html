📚 데이터 조회의 마법:
SELECT와 WHERE 기초

데이터베이스(DB)에서 가장 많이 쓰이는 명령어는 무엇일까요? 바로 데이터를 읽어오는 DML(데이터 조작어)의 핵심, SELECT입니다.

이번 시간에는 테이블에 저장된 수많은 데이터 중에서, 내가 원하는 정보만 입맛대로 골라오고(SELECT) 필터링(WHERE)하는 다양한 방법을 실습해 보겠습니다.

🔍 1. 원하는 데이터만 쏙쏙 뽑아오기 (기본 SELECT)

테이블의 모든 내용을 보거나, 특정 칸(컬럼)만 골라보는 가장 기초적인 명령어입니다.

1-1. 테이블 전체 조회하기

-- 별표(*)는 '테이블의 모든 컬럼'을 의미합니다. SELECT * FROM STUDENT; SELECT * FROM SUBJECT; SELECT * FROM ENROL;

1-2. 특정 컬럼만 골라서 조회하기

-- 학생 테이블에서 학번, 이름, 학과 정보만 깔끔하게 추려옵니다. SELECT STU_NO, STU_NAME, STU_DEPT FROM STUDENT;

🎯 2. 조건 달기 (WHERE 연산자)

WHERE 절을 사용하면 내가 원하는 특정 조건을 만족하는 행(데이터)만 필터링할 수 있습니다.

2-1. 같다(=) / 다르다(!=)

-- '기계'과 학생들만 조회 SELECT * FROM STUDENT WHERE STU_DEPT = '기계'; -- '기계'과가 아닌 타 학과 학생들만 조회 SELECT * FROM STUDENT WHERE STU_DEPT != '기계';

2-2. 크기 비교 연산자 (>=, >)

-- 키가 168 이상(포함)인 학생들 조회 SELECT * FROM STUDENT WHERE STU_HEIGHT >= 168; -- 키가 168 초과(미포함)인 학생들 조회 SELECT * FROM STUDENT WHERE STU_HEIGHT > 168;

🧩 3. 여러 조건 엮기 (AND, OR, IN)

조건이 두 개 이상일 때는 논리 연산자를 사용해 복잡한 검색을 수행합니다.

3-1. AND (모두 만족) / OR (하나라도 만족)

-- [AND] 전기전자과 '이면서' 성별이 남자인 학생 조회 SELECT * FROM STUDENT WHERE STU_DEPT = '전기전자' AND STU_GENDER = 'M'; -- [OR] '컴퓨터정보' 학과 '이거나' 3학년인 학생 조회 SELECT * FROM STUDENT WHERE STU_DEPT = '컴퓨터정보' OR STU_GRADE = 3;

3-2. IN 연산자 (여러 값 중 하나라도 포함되면 참)

-- 1학년이거나 3학년인 학생 출력 (OR를 여러 번 쓰는 것보다 훨씬 깔끔합니다!) SELECT * FROM STUDENT WHERE STU_GRADE IN (1, 3); -- 위 코드는 아래 코드와 완벽히 똑같이 작동합니다. -- WHERE STU_GRADE = 1 OR STU_GRADE = 3;

✨ 4. 특수 검색 (NULL과 LIKE)

4-1. 빈 칸 찾기 (IS NULL)

데이터베이스에서 NULL은 '값이 아직 입력되지 않은 빈 상태'를 의미합니다. `=' 기호로는 절대 찾을 수 없고, 반드시 IS NULL을 써야 합니다.

-- 키 정보가 누락된(빈 값인) 학생들 찾기 SELECT * FROM STUDENT WHERE STU_HEIGHT IS NULL; -- 반대로 키 정보가 정상적으로 입력되어 있는 학생들만 찾기 SELECT * FROM STUDENT WHERE STU_HEIGHT IS NOT NULL;

4-2. 패턴 검색 (LIKE 연산자)

정확한 값을 모를 때, 특정 단어가 포함되어 있는지를 검색합니다.
(% = 길이에 상관없이 모든 문자열, _ = 정확히 한 글자)

-- 학번이 '2015'로 시작하고 뒤에 정확히 4글자가 더 있는 학생 (총 8자리 학번) SELECT * FROM STUDENT WHERE STU_NO LIKE '2015____'; -- 학번이 무엇으로 시작하든 끝자리가 '5'로 끝나는 학생 SELECT * FROM STUDENT WHERE STU_NO LIKE '%5';
💡 기억해 두세요!
LIKE '%김%' 이라고 검색하면 이름 중간에 '김'이 들어간 모든 사람을 찾아낼 수 있습니다. 게시판의 '제목 검색' 기능이 바로 이 LIKE 연산자를 사용해 만들어집니다.
